## Project Objective

To evaluate the accuracy of converting **chat-style Singlish** input into **Sinhala** output by executing 50 test cases covering all 24 Singlish input types specified in the assignment.

---

## Prerequisites

- Python 3.11 or 3.12
- Google Chrome (recommended) or Chromium (installed by Playwright)

---

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/sandu343/ITPM-Assignment-1--Automation.git
cd ITPM-Assignment-1--Automation

2. Install Dependencies
Open Command Prompt (or PowerShell) and run the following commands:
Bash# Upgrade pip
python -m pip install -U pip

# Install required packages
python -m pip install playwright openpyxl

# Install Playwright browsers
python -m playwright install chromium
Note: If you face permission issues, run the commands in an administrator Command Prompt or use --user flag.
3. Prepare Test Data

Open the Excel file: Assignment 1 - Test cases.xlsx
Ensure your 50 test cases are filled in columns A to D (TC ID, Input length type, Input, Expected output).


How to Run the Tests

Navigate to the project folder in Command Prompt and run:
Bashpython test_automation.py --excel "IT23192096-Assignment 1 - Test cases.xlsx" \
  --url "https://www.pixelssuite.com/chat-translator" \
  --wait-ms 5000 \
  --type-delay-ms 80 \
  --slow-mo-ms 200 \
  --save-every 1 \
  --keep-open

Command Explanation

--excel → Path to the Excel file
--wait-ms → Wait time before typing
--type-delay-ms → Delay between keystrokes
--slow-mo-ms → Slow motion for visibility
--keep-open → Keep browser open after execution
